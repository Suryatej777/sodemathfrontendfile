# How to Build Your App APK (Step-by-Step)

Since I have already set up the Android project for you, you just need to turn it into an APK file using Android Studio.

## Step 1: Install Android Studio
1.  Go to [developer.android.com/studio](https://developer.android.com/studio).
2.  Download and install **Android Studio** for Windows.
3.  Open it and follow the setup wizard (make sure to install the "Android SDK" when asked).

## Step 2: Open the Project
1.  Open Android Studio.
2.  Click **Open**.
3.  Navigate to this folder:
    `c:\Users\surya\.gemini\antigravity\scratch\sode-matha-web\android`
4.  Click **OK**.
5.  Wait a few minutes for "Gradle Sync" to finish (you'll see progress bars at the bottom).

## Step 3: Build the APK
1.  In the top menu, click **Build**.
2.  Select **Build Bundle(s) / APK(s)** > **Build APK(s)**.
3.  Wait for the build to finish.

## Step 4: Get the APK
1.  A pop-up will appear in the bottom-right corner saying "Build APK(s): APK(s) generated successfully".
2.  Click the blue **locate** link in that pop-up.
3.  It will open a folder with `app-debug.apk`.
4.  **This is your app!** 📱

## Step 5: Install on Phone
1.  Send this `app-debug.apk` file to your phone (via WhatsApp, Google Drive, or USB).
2.  Tap on it to install.
3.  Enjoy your Sode Matha App!
